# ChatPet

Google Chat의 새 메시지를 데스크톱 Pet으로 알려주는 Windows 앱입니다.

이 저장소는 ChatPet의 실행 파일, 설치 프로그램, 변경 사항을 제공하는 공개 배포 공간입니다.

## 다운로드

현재 첫 공개 배포를 준비하고 있습니다. 아직 이 저장소에 다운로드 파일이나 자동 업데이트 피드가 게시되지 않았습니다.

배포가 시작되면 [Releases](https://github.com/Yoodaddy0311/chatpet-releases/releases)에서 다음 파일을 받을 수 있습니다.

| 파일 | 용도 |
|---|---|
| `ChatPetSetup.exe` | Windows에 설치하여 사용 |
| `ChatPet.exe` | 설치 없이 바로 실행 |

## 업데이트

1.2.14에 실행 전 업데이트 확인 기능을 구현했습니다. 공개 Release를 게시하면 이후 버전을 앱에서 확인하고 설치할 수 있습니다. 설정에서 직접 확인하거나 시작 시 확인을 끌 수도 있습니다.

1.2.13 이하의 기존 사용자는 기능이 포함된 첫 버전을 한 번 직접 설치하거나 실행 파일을 교체해야 합니다. 아직 이 저장소에는 1.2.14 배포 파일이 게시되지 않았습니다.

각 릴리스에 변경 사항과 설치 안내를 함께 제공합니다.
