# ChatPet

Google Chat의 새 메시지를 데스크톱 Pet으로 알려주는 Windows 앱입니다.

이 저장소는 ChatPet의 실행 파일, 설치 프로그램, 변경 사항을 제공하는 공개 배포 공간입니다.

[ChatPet 홈페이지 — Pet 만나보기와 다운로드](https://yoodaddy0311.github.io/chatpet-releases/)

## 읽은 뒤 원래 자리까지 걸어서 복귀

새 메시지 때문에 이동한 Pet은 모두 읽은 뒤 처음 자리까지 걸어서 돌아가 잠듭니다. 도착 직전에는 속도를 줄입니다. 추가 메시지가 오면 알림에 반응하고, 모두 읽으면 처음 자리로 다시 돌아옵니다. 직접 드래그하거나 위치 버튼으로 옮기면 새 위치가 기준이 됩니다.

Pet을 눌러 대화를 열 때는 연결된 계정을 확인한 Chrome 프로필을 사용하도록 개선했습니다.

## 업데이트 파일 정리와 요청량 조절

검증된 복구 백업은 최근 2개를 남기고 완료된 업데이트 파일과 7일 이상 지난 중단 작업을 자동 정리합니다. 설치·복구 중이거나 사용 중인 자료는 보호합니다. 오래된 일반 로그와 회전 로그도 함께 정리합니다.

배포 전에는 실행파일 검사의 새 결과와 최종 성공 기록을 확인합니다. 결과가 없거나 중간에 종료된 검사는 통과로 처리하지 않습니다.

## 저장소 누적과 반복 경고 수정

완료된 조회 이력이 계속 쌓여 내부 저장 한도에 걸리던 문제를 수정했습니다. 계정별 최근 256회와 진행 중인 조회를 보존하고 불필요한 기록과 빈 공간을 자동 정리합니다. 저장 오류는 상태에 표시하고 1분 후 재시도하며, 같은 경고창을 매초 반복하지 않습니다. 기존 로그인·Pet 설정·읽음 상태는 유지합니다. 이미 오류로 실행이 어려우면 새 설치파일로 설치해 복구할 수 있습니다.

## 읽은 메시지가 미확인으로 남는 문제 수정

검색에서 안 읽음으로 남은 스레드 답글은 해당 스레드의 실제 읽음 시각을 추가 확인합니다. 요청한 시간·대화 범위 밖의 검색 결과도 제외해 과거 메시지가 다시 알림에 섞이지 않도록 했습니다. 일반 대화와 기존 알림 설정은 유지합니다.

## 수신과 읽음 확인 개선

미확인 메시지가 있는 동안과 최근 활동 후 2분 동안은 새 메시지를 2초 간격, 읽음 상태를 3초 간격으로 확인합니다. 최신 메시지 조회를 우선하고 백그라운드 조회량을 조절합니다. 한동안 조용하면 새 메시지 조회를 10~12초 간격으로 줄이며, 새 미확인 메시지를 발견하면 빠른 읽음 확인으로 돌아옵니다. 여러 설치본이 요청 한도를 공유하므로 Google의 제한 응답이 오면 조회 속도를 낮추고 재시도를 분산합니다. 서버의 대기 지시를 지키며 안정적으로 복구합니다. Google API·검색 반영·네트워크·대화 수에 따른 지연은 남을 수 있습니다.

## Google 로그인 → Pet 선택

앱에 로그인 설정을 포함해 새 PC에서도 JSON 파일 선택 없이 Google 로그인을 시작합니다. 첫 연결에 성공하면 Pet을 선택할 수 있습니다. 로그인 전에 테스트 메시지가 생성되던 문제도 수정했습니다.

**현재 테스트 운영 중으로, 등록된 테스트 계정만 Google Chat에 연결할 수 있습니다.** 일반 사용자 공개 연결은 Google 검증을 준비 중입니다. 회사의 관리자 정책에 따라 연결이 제한될 수 있습니다. 설치파일은 GitHub 로그인 없이 받을 수 있습니다.

[개인정보처리방침](https://yoodaddy0311.github.io/chatpet-releases/privacy.html)

## 숨긴 스페이스 알림 제외

설정 → 스페이스 관리에서 **숨긴 스페이스 알림 제외**를 켜고, 제외할 스페이스의 **숨김 목록에 포함**을 선택한 뒤 저장하세요. 기본값은 켜짐이며, 옵션을 끄면 원래 알림 범위로 돌아갑니다. 목록은 계정별로 저장됩니다.

**Google Chat의 숨김 목록과 자동으로 동기화되지 않습니다.** ChatPet에서 직접 지정하는 목록이며, Google Chat의 설정이나 메시지 읽음 상태를 변경하지 않습니다. 개인 DM과 그룹 대화의 기존 알림은 유지됩니다.

## 업데이트

1.2.14 이상은 **설정 → 일반 → 앱 정보 → 업데이트 확인**에서 새 버전을 설치할 수 있습니다. 시작 시 확인을 켜 두면 재실행할 때 안내하며, 실행 중에도 주기적으로 확인합니다. 사용자가 업데이트를 선택하면 설치하고, 나중에 진행할 수도 있습니다. 기존 로그인·Pet·알림 설정은 유지합니다.

1.2.13 이하의 기존 사용자는 이번 버전을 한 번 직접 설치하거나 실행 파일을 교체해야 합니다. 기존 ChatPet을 트레이 메뉴에서 종료한 뒤 진행하세요. 이후 더 높은 버전을 게시하면 앱에서 업데이트를 안내합니다.

각 릴리스에 변경 사항, 설치 안내와 서명된 업데이트 정보를 함께 제공합니다. 현재 실행 파일에는 Windows 코드 서명이 적용되지 않았으며, 업데이트 정보에는 별도의 배포 서명과 파일 검증을 적용했습니다.
